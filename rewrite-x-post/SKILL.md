# rewrite x post

短い日常文や下書きを、元の温度、言い回し、生活感を残したX投稿候補へリライトする。ニュース検索やWeb検索は行わない。

## 方針

- 元文の人間味や素の感じを残し、別人の文章にしない。
- いきなり教訓化せず、共感、観察、余韻を必要最小限だけ足す。
- 短い断片を並べるテンポを使ってよい。空行は多用しない。
- 通常案は3〜6行、70〜220文字を目安にし、公式カウントで280文字以内にする。
- 関西らしい言い回しがある場合は標準語へ直しすぎず、冒頭かセルフツッコミに2〜3箇所以内で残す。
- 絵文字は通常案0〜2個、勢いある案2〜4個まで。候補全体で少なくとも1本は絵文字入りにする。
- ユーザーが絵文字を求めた場合は、おすすめと勢いある案の両方へ自然な絵文字を1個以上入れる。

## AI臭さを避ける

- 元文にない深い比喩、広告コピー、整いすぎた対比、いい話を足さない。
- 「人間に戻る」「生活が置いていかれる」「正解な気がしている」のような作った余韻を避ける。
- 「差し引きゼロ」「こういう日も必要」のような教訓やきれいなオチで畳まない。迷ったら「分からん」「まあええか」程度で止める。
- 文末装飾だけの絵文字を避ける。

## 勢いある案

- 前半を状況説明、中盤を短い事実の断片、最後を理由やオチにする。
- 短いツッコミ、改行、感嘆符を使ってよい。`‼‼` はこの案だけで使う。
- 「誰や〜」「〜言うたのは」のような強いセルフツッコミは1行までにする。

## 例

入力:

```text
作業はじめたら日をまたいでもうたやないか
```

出力例:

```text
作業はじめたら日をまたいでもた。
誰や「ちょっとだけやる」って言うたのは・・‼‼

進捗は出た。
腹は減った。
軽く飲みに行く理由もできた‼‼🍺
```

## 出力

- 判定: 通常ツイートリライト
- 変換方針: 1文
- `おすすめ` 1本、`勢いある案` 1本、方向性の異なる `別案` 3本を出す。
- 各候補は、そのまま貼れる本文だけを個別の `text` コードブロックに入れる。
- 分析、ニュース一覧、出典、スペース告知、リプ案、引用ポスト案、記事化案は出さない。

## 最終確認

- 元文の温度と本人らしさが残っている。
- 5本のリズム、締め方、絵文字が均一になっていない。
- 根拠のない数字、過剰な煽り、誹謗中傷、読者を見下す表現がない。
- 公式カウント（全角・日本語は1文字2、半角は1、URLは一律23、上限280。日本語140字相当）で各280以内。コードで実測し、できない場合は未検証と明記する。超過時は、末尾の独立ハッシュタグを本文中の語のタグ化へ移し、リンクカードで分かるサービス名は短くして削る。
